# T1.7 M1 契约收口实现计划

> 实施方式：严格按测试驱动开发执行；每个任务先写失败测试并确认失败原因，
> 再写最小实现，运行局部与全量验证后提交。每个任务提交后进行独立审查，
> 重要问题在进入下一任务前修复。

**目标：** 把 M1 复核发现的四处缺口收口，使「冻结全集」在文档、生产端和
契约库三处一致，并保持后续命令接入成本仍为一行 `contracttest.Register`。

**架构：** 归一化落在 `ProcessOutput` 串行化临界区内、renderer 之前，因此
NDJSON 与 human 共用同一结果；全集成员断言落在 `contracttest`，作为对
「绕过构造函数」的 transcript 层防线；文档驱动比对统一收敛到
`doc_fixture_test.go`。设计见 [设计-T1.7](./设计-T1.7-M1契约收口.md)。

**技术栈：** Go 标准库（`encoding/json`、`os`、`regexp`、`slices`、`strings`），
现有 protocol 事件 / 错误 / stage / contracttest API。**不新增第三方依赖。**

**公共前置：**

```powershell
$ErrorActionPreference = "Stop"
$go = (Get-Command go -ErrorAction Stop).Source
$gofmt = (Get-Command gofmt -ErrorAction Stop).Source
$gccBin = Split-Path -Parent (Get-Command gcc -ErrorAction Stop).Source
$env:PATH = "$gccBin;$env:PATH"
$env:GOCACHE = Join-Path $env:TEMP "auto-mas-runtime-t17"

function Invoke-Checked {
    param(
        [scriptblock]$Command,
        [string]$Name
    )
    $output = @(& $Command 2>&1)
    $exitCode = $LASTEXITCODE
    $output
    if ($exitCode -ne 0) {
        throw "$Name failed with exit code $exitCode"
    }
}

function Invoke-CheckedTargetedTest {
    param(
        [string]$Package,
        [string]$Pattern
    )
    $output = @(& $go test $Package -run $Pattern -count=1 -v 2>&1)
    $exitCode = $LASTEXITCODE
    $output
    $text = $output -join [Environment]::NewLine
    if ($exitCode -ne 0) {
        throw "targeted test failed with exit code $exitCode"
    }
    if ($text -match "\[no tests to run\]" -or $text -notmatch "--- PASS:") {
        throw "targeted test did not produce a passing test result"
    }
}

function Invoke-ExpectedFailingTargetedTest {
    param(
        [string]$Package,
        [string]$Pattern,
        [string]$ExpectedFailure
    )
    $output = @(& $go test $Package -run $Pattern -count=1 -v 2>&1)
    $exitCode = $LASTEXITCODE
    $output
    $text = $output -join [Environment]::NewLine
    if ($exitCode -eq 0) {
        throw "red test unexpectedly passed"
    }
    if ($text -match "\[no tests to run\]" -or $text -notmatch "(--- FAIL:|build failed)") {
        throw "red test did not produce the expected failing test result"
    }
    if ($text -notmatch $ExpectedFailure) {
        throw "red test failed for an unexpected reason"
    }
}
```

所有原生命令都必须通过上述检查器执行；用 `Invoke-CheckedTargetedTest`
定向跑时同时确认退出码为 0、输出不含 `[no tests to run]` 且出现 `--- PASS:`。
TDD 红灯改用 `Invoke-ExpectedFailingTargetedTest`，同时证明失败来自预期缺口。
