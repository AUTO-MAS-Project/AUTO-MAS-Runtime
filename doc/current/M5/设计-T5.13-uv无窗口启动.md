# T5.13 一次性 uv 命令无窗口启动

Issue #13 报告偶发出现终端窗口。源码确认 `UVRunner.Run` 使用普通
`exec.CommandContext`，没有配置 Windows 启动属性；`process.StartManaged`
已有 `HideWindow` 与 `CREATE_NO_WINDOW`。报告中的管道错误缺少现场复现，
本任务只修复已确认的启动属性遗漏。

在普通 Run 的命令创建后调用包内平台函数，Windows 实现设置
`syscall.SysProcAttr{HideWindow: true, CreationFlags: windows.CREATE_NO_WINDOW}`。
非 Windows 文件提供空实现，维持当前平台不支持 Job 的边界。不使用 shell、
`DETACHED_PROCESS` 或 `CREATE_NEW_CONSOLE`；不调整长驻后端、Job、管道和取消逻辑。

真实 Windows 测试子进程通过 `GetConsoleWindow` 返回关联控制台句柄，断言为 0；
同时验证含空格与中文的参数、stdout/stderr，以及成功和非零退出行为。
既有版本检查与取消测试提供其余回归覆盖。

依据：[Microsoft 进程创建标志](https://learn.microsoft.com/en-us/windows/win32/procthread/process-creation-flags)
说明 `CREATE_NO_WINDOW` 使控制台应用没有控制台句柄；
[GetConsoleWindow](https://learn.microsoft.com/en-us/windows/console/getconsolewindow)
在没有关联控制台时返回 NULL，伪控制台则仍会返回非零句柄。

本任务不改协议、目录、镜像与错误码，不发布或关闭 Issue。
