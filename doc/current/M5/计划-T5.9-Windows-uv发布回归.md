## 3. Task 2：离线 typed error 与 mutation 终态收口

文件：`internal/uv/bootstrap.go`、M5 CLI transaction helper、environment ensure 测试及必要假件。

固定测试：

- `TestEnvironmentEnsure_OfflineCacheMissReturnsNetworkUnavailable`
- `TestEnvironmentEnsure_TerminalFailureRemovesMutation`

`TestEnvironmentEnsure_TerminalFailureRemovesMutation` 的表驱动子项固定为：
`offline_cache_miss`、`download_failure`、`checksum_mismatch`、`extract_failure`、
`publish_failure`、`version_mismatch`、`success`、`cancel`、`state_delete_failure`。

```powershell

$output
if ($code -eq 0) { throw "expected offline or mutation regression red test" }
if ($output -match '\[no tests to run\]') { throw "target tests did not run" }
```

绿灯与重复：

```powershell
$output = & go test ./internal/cli -run $pattern -count=20 2>&1
$code = $LASTEXITCODE
$output
if ($code -ne 0) { throw "offline/mutation tests failed" }
if ($output -match '\[no tests to run\]') { throw "target tests did not run" }
foreach ($name in @('TestEnvironmentEnsure_OfflineCacheMissReturnsNetworkUnavailable','TestEnvironmentEnsure_TerminalFailureRemovesMutation')) {
    if ($output -notmatch "--- PASS: $name") { throw "$name did not pass" }
}
```

实现边界：离线零 source attempt 的 typed `NETWORK_UNAVAILABLE` 不被包装；在线失败保持原码。
收口 helper 接收 snapshot，以独立 30 秒 context 先完成生命周期处理，再执行 StateFiles 条件删除；
无法确认所有权或自身 cleanup/state 失败时保留证据。

提交建议：`fix: 收口离线错误与 uv mutation 事务 (T5.9)`。
