# T5.15 源码包构建依赖镜像索引

Issue #25 中锁内制品已正常使用镜像，源码包构建所需的 setuptools / wheel
仍请求官方 PyPI。锁副本的 registry 改写不能替代构建环境的默认索引设置。

在 `runStagedSyncWithEnvironment` 向共用的 `mirrorSyncArguments` 传入
`rewrite.SimpleBase()`，追加 `--default-index` 参数。中继启动时该值是回环
`/simple`，逐源镜像路径每次使用当前源的 simple 地址。

只修改 `--frozen` 锁副本安装。原锁的 `uv lock --check`、直接 `--locked`
同步和离线路径不加覆盖参数；不修改仓库项目声明和锁文件、不关闭构建隔离，
不新增环境放行键、错误码或外层重试。同步失败、取消、镜像耗尽、临时目录和
Relay 关闭沿用既有路径。先修订架构与增补 2 C17，再实现本任务。

组件测试以本地 TLS 镜像和真实 Relay 验证构建依赖的 simple 页与 wheel 请求，
uv 替身模拟构建依赖解析入口，不把该测试描述为真实 Python 构建验收。
原锁检查和离线回退由现有精确参数与环境断言回归。
