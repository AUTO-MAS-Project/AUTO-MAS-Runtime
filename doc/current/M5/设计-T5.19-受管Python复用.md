# T5.19 复用可用的受管 Python

v5.9.0 热更新前后都要求 Python 3.12.13。Runtime 进入完整准备流程时，uv 0.12.3 会尝试重建 3.12 的目录链接，现有非空条目可导致 Windows 错误 145，即使 3.12.13 解释器本身可用。

由 `PythonService.Prepare` 在现有版本检查后、进入分发源规划前检查已安装的解释器。用固定 uv 离线查询精确版本，忽略项目和虚拟环境，绕过查询缓存，以当次解释器结果判断能否复用。查询正常由 uv 返回非零退出码时走既有安装与复核流程。取消或执行层失败沿用原错误。显式重装直接使用既有安装流程。

准备仍由原有生命周期和环境锁管理。复用结果沿用安装成功的版本字段，分发源和中继字段为空。依赖同步仍由调用方执行。目录链接与用户数据保留，所属协议与错误码不变。

本地验收：Windows 隔离目录中，真实 uv 0.12.3 的安装命令因非空链接路径退出 2（错误 145）。改后 `Prepare` 复用 Python 3.12.13，后续 `Sync` 和 `Check` 成功，冲突目录中的标记文件仍在。定向回归先红后绿，race 定向测试重复 10 次通过，本机 PowerShell 全仓测试通过。
