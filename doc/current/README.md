# 当前工作文档

本目录只存放尚未完成任务的设计与实施计划。每个里程碑使用独立子目录，避免所有文件堆在
`doc/` 根目录。

当前实施阶段为 M3 收口（T3.7 功能缺口修复、T3.8 可维护性重构，
见 [`M3/计划-T3.7-T3.8.md`](./M3/计划-T3.7-T3.8.md)）；两者完成后进入
M4 工作区同步（internal/gitrepo）。

任务完成后的处理规则：

- 设计文档若仍能解释当前实现，移入 `../archive/M<里程碑>/`；
- 已执行完成的计划删除，由 Git 历史负责追溯；
- 任务进度和最终提交证据回写 `../任务拆分.md`。
