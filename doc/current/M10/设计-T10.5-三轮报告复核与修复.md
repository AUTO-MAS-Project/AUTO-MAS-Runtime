# T10.5 三轮报告复核与修复

日期：2026-10-12；基线：99d81e9。根目录九份 GLM 报告是待核实输入，不能替代权威契约。

## 判定与范围

需要修复：I1 Git 传输预算、I2 uv 管道收口、I3 文件日志错误优雅关闭、I5 lock exFAT 回退、I7 中继异常退出、I9 warning-only 失败终态；R2-3 guard 等待预算、R2-5 未知制品大小限制、R2-6 breakaway 管道收口、R2-7 CI Action 钉扎、R2-8 依赖修复线；R2-1 健康身份与关闭鉴权由用户明确授权同步修改 AUTO-MAS 后端。

不照搬：I8 ServerName 清空符合现有隐私白名单，应保留；I4 无法确认后代必须失败关闭，简单等待三次不能恢复已经退出的父链；I6 未提供 ReFS 实机证据，不放宽能力白名单；I10 固定 1 GiB 阈值不能证明所需空间且会误拒小仓库；R2-4 规划失败仅损失中继纵深，uv 的锁内摘要验证仍在，不能增加 host 白名单拒绝合法自定义依赖。

工程建议：R3-1/4/5/6 的大型重构、R3-9 批量并行和 R3-11/12 删除路径优化不属于当前正确性修复必要条件；保留身份复验与测试隔离。R3-14 直接落盘原始 cause 可能泄漏 URL 凭据，不采用；R3-13 开放 failureKind 是已有诊断契约，不改为封闭枚举。

R2-2 的 Global Mutex 涉及旧 Runtime Local 命名互操作和多用户 ACL，须单独设计迁移；R2-11 同用户预占属于可用性边界，不能声称 marker 能阻止有目录写权的攻击者。R2-9 文件回收必须保护正在交付的读者与后续重新取回；R2-12 的安全修复必须在调用方持有 staging 祖先和目录租约，不能让 relay 反向依赖 filesystem 形成循环，也不能用一次 Lstat 代替句柄钉链。
