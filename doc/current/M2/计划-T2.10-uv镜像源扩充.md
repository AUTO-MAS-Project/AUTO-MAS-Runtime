### 红灯

1. 修改 `TestDefaultCatalog_ExactSourcesAndOrder`，精确加入 `agentsmirror`、
   `cdn-gh-proxy`和 `edgeone-gh-proxy` 的 key、Base URL 与顺序。
2. 执行：

   ```powershell
   $output = & go test ./internal/mirror -run '^TestDefaultCatalog_ExactSourcesAndOrder$' -count=1 -v 2>&1
   $code = $LASTEXITCODE
   $output
   if ($code -eq 0) { throw "expected catalog test to fail before implementation" }
   if ($output -match '\[no tests to run\]') { throw "catalog test did not run" }
   if ($output -notmatch '--- FAIL: TestDefaultCatalog_ExactSourcesAndOrder') {
       throw "catalog test did not fail for the expected test"
   }
   ```

3. 失败必须是 uv Source 数量或顺序与新期望不符，不得是编译、无测试运行或环境错误。
