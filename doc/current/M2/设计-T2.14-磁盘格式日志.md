# T2.14 磁盘格式日志

日期：2026-10-18。

每次 `logging.New` 成功打开日志后，写一条 info 诊断「当前磁盘格式：NTFS」；details 保存 `path`（`layout.AppRoot()`）与 `fileSystem`。该诊断沿既有能力同步写入 `debug/runtime` 日志和 stderr，覆盖初始化、更新、依赖与后端监督等实际创建日志的路径。

将 doctor 现有 Windows 只读卷格式探测移入 `filesystem.FileSystemName` 共用；通过 `GetVolumePathName` 定位实际卷，不能只按盘符判断，以兼容挂载目录。非 Windows 返回不支持。探测错误或空值统一记录 `unknown`，不输出底层原始错误，不改变命令结果、文件系统支持范围、stdout 协议或遥测字段。诊断写入失败遵守既有日志失败行为，关闭已打开资源后返回错误。

不新增并发、缓存、外部进程或网络请求。先以注入探针证明 NTFS/exFAT/失败/空值行为，再用真实临时目录证明生产构造器已接线以及 doctor 仍能读取卷格式；完整执行格式、vet、build、test 与 diff 检查。
