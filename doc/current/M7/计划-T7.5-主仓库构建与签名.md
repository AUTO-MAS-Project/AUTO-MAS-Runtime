验证（PowerShell 7）：

```powershell
$env:GOCACHE = Join-Path $env:TEMP 'auto-mas-runtime-verify'
$result = & go test ./internal/release -run 'TestSigningRequest_EndToEnd|TestRuntimeRelease_MetadataAndUnsignedRejection|TestReleaseWorkflow_SigningContract' -v -count=1 2>&1
$code = $LASTEXITCODE
$result
if ($code -ne 0 -or "$result" -match '\[no tests to run\]' -or "$result" -notmatch '--- PASS:') { throw 'targeted verification failed' }
```

暂存只使用上述文件白名单。主仓库提交后普通 fast-forward push 到 `refs/heads/dev`，
不推 main；Runtime 在本地 main fast-forward，Runtime push 另按用户授权范围处理。
