### 红灯

新增 `TestReleaseWorkflow_VersionedExecutableName`，要求 metadata 从 release tag 生成
`auto-mas-runtime-<version>.exe`，并要求 build、upload、publish、smoke 全链路使用动态
`binary_name`。在固定 `auto-mas-runtime.exe` 的现状上运行：

```powershell
$env:GOCACHE = Join-Path $env:TEMP "auto-mas-runtime-t76-red"
$output = & go test ./internal/release -run '^TestReleaseWorkflow_VersionedExecutableName$' -count=1 -v 2>&1
$exitCode = $LASTEXITCODE
$output
if ($exitCode -eq 0) { throw "red test unexpectedly passed" }
if ($output -match '\[no tests to run\]') { throw "red test did not run" }
if ($output -notmatch '--- FAIL: TestReleaseWorkflow_VersionedExecutableName') {
  throw "red test failed for an unexpected reason"
}
```

### 绿灯

在 workflow metadata 中从已校验 tag 生成动态文件名；后续步骤只消费该输出，并继续校验唯一
EXE 与对应 SHA-256：

```powershell
$env:GOCACHE = Join-Path $env:TEMP "auto-mas-runtime-t76-green"
$output = & go test ./internal/release -run '^TestReleaseWorkflow_VersionedExecutableName$' -count=1 -v 2>&1
$exitCode = $LASTEXITCODE
$output
if ($exitCode -ne 0) { throw "green test failed" }
if ($output -match '\[no tests to run\]') { throw "green test did not run" }
if ($output -notmatch '--- PASS: TestReleaseWorkflow_VersionedExecutableName') {
  throw "green test pass marker missing"
}
```
