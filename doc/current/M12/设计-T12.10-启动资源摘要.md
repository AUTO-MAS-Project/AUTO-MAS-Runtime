# T12.10 启动错误资源摘要

桌面在明确启用硬件遥测的启动尝试中，为每个 Runtime 子进程生成独立的 64 位小写十六进制随机串，通过 AUTO_MAS_STARTUP_SAMPLE 传递。前 32 位构成本机命名管道 auto-mas-startup- 后缀，后 32 位属于一次会话的读取凭据。Runtime 不向 uv 或后端继承该变量。窗口与后端均无法通过业务 IPC 获取凭据。

支持此扩展的 Runtime 在受邀会话的 hello 中宣告 startup.resources.v1。向 Sentry 发送原已允许的初始化错误时，最多花 120 毫秒连接本机命名管道，写入凭据及换行并读取最多 32 KiB 的 JSON 对象。桌面只在握手、启动尝试与采集代次匹配时返回有限字段。旧桌面不提供变量，旧 Runtime 不宣告能力。普通成功、取消和离线不请求。退出或超时丢弃本次附加信息。

允许的字段由 internal/telemetry/startup_fields.json 定义。错误在发送前重新校验字段和值。startup_resources 上下文适用于原有的运行错误、内部错误及 panic，分组和业务结果沿用既有规则。

受邀命令在终态 details.startupArchive 中返回本次 uv 归档缓存命中及实际校验、解包毫秒数，未执行的步骤省略。桌面按区间汇总。

关闭匿名遥测时，桌面仍可传入固定值 local 获取本地归档耗时。该值不含管道凭据，不能读取或上传硬件摘要。
