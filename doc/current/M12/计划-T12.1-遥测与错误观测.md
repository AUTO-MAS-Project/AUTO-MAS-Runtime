2. provider 测试统一使用消费方定义的 fake transport/provider；不得使用真实公网、真实凭据或

3. `--offline` 与 `AUTO_MAS_TELEMETRY=disabled` 的断言必须覆盖“client 尚未创建”这一点，
   不能只断言发送次数为零。
4. 每个 Task 一个提交，只暂存该 Task 文件清单；提交前执行 `git diff --check`，不使用
   `--no-verify`。本轮文档任务由父任务统一检查，不在此处提交。
5. 所有验证命令使用 PowerShell 7，并在每个原生命令后检查 `$LASTEXITCODE`。

## T12.4 Sentry adapter 与净化

### 文件

- `internal/telemetry/sentry.go`
- `internal/telemetry/sentry_test.go`
- `go.mod`、`go.sum`（官方 `sentry-go` 固定版本）

### 红灯

固定测试名：

- `TestSentry_CapturesOnlyInternalError`
- `TestSentry_CapturesUnexpectedPanicWithoutPanicValue`
- `TestSentry_BeforeSendRemovesPIIAndRawText`
- `TestSentry_SanitizesStackFramePaths`
- `TestSentry_DisablesTracingLogsAndDefaultPII`
- `TestSentry_MissingDSNOfflineAndFailureAreSilent`

测试事件需包含绝对路径、主机名、用户名、request、server、breadcrumb、extra、原始 error/
panic 文本等反例，并证明发送 payload 中不存在这些值；预期网络/参数/取消错误不得产生事件。

### 绿灯

- DSN 缺失、关闭、offline 时不构造 hub/transport；
- `AUTO_MAS_SENTRY_ENVIRONMENT` / `AUTO_MAS_SENTRY_RELEASE` 只接受低基数安全元数据，非法值
  回退固定默认值；
- `SendDefaultPII=false`、`EnableTracing=false`、`DisableLogs=true` 固定生效；
- `BeforeSend` 只重建固定消息、severity、release/environment、允许标签和函数/模块/行号；
- panic 栈边界最多采样 32 帧，provider 拒绝超过 64 帧；每帧只保留 function/module/非负
  line（各 256 字节上限），所有路径、vars 和源码上下文净化；
- 网络失败、flush 超时和 close 错误静默；不改变既有 `INTERNAL_ERROR` 四元组。

### 验证

```powershell

if ($LASTEXITCODE -ne 0) { throw "T12.4 focused tests failed" }
```
