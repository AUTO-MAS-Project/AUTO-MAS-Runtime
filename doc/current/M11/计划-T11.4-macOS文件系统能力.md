基线：`ff2d5f7`。边界：用户已确认的同 UID 信任范围；生产 CLI 暂不开放。Windows 全量门保留，Darwin 用原生 Runner 执行替代矩阵，不把交叉编译当通过证据。

本轮状态（2026-11-09）：Task 1~3 历史原生结果保留。同步主分支后，分卷日志、rooted Git、源码恢复和下载故障注入已在适配分支提交；Windows 标准门与 Darwin 交叉验证通过。macOS 15/26 双 APFS 原生验证尚未运行，T11.4 仍保留进行中状态。详见 [验证记录](./验证-T11.4-macOS文件系统能力.md)。

## Task 1：目录与普通文件身份

- 文件：`internal/filesystem/*_darwin.go`、`directory.go`、`directory_darwin_test.go`、原生工作流。现有 `delete_test.go` 直接导入 Win32，只明确标记 Windows；Darwin 安全用例另建，不能宣称该门已移植。
- 红灯：`TestDarwinDirectory_PrepareAndInspect`、`TestDarwinDirectory_RejectsUnsafePaths`、`TestDarwinFile_RejectsLinksAndSpecialFiles`、`TestDarwinDirectory_CancellationAndIdentity`，在真实 APFS 上确认现有桩拒绝正常操作；复查追加 `TestDarwinDirectory_RejectsCrossDeviceBeforeCreate`，设备不匹配必须在 mkdir 之前拒绝。
- 绿灯：只认本地 APFS；根打开时仅允许系统固定 `/tmp -> /private/tmp`、`/var -> /private/var` 别名。使用逐层 `openat(O_DIRECTORY|O_NOFOLLOW)` 与设备/inode 身份，不跟随任意祖先链接；文件拒绝符号链接、非普通类型及多硬链接。目录租约持有 FD，关闭幂等。创建不覆盖现有对象，未知现场保留。
- 验证：两档原生 Runner、两种 APFS 大小写模式的上述测试 + race；Windows 标准门。提交 `feat: 实现 macOS 目录与文件身份 (T11.4)`。

## Task 2：下载和日志能力

- 文件：`download_files_darwin.go`、`runtime_logs_darwin.go` 及对应测试。
- 红灯：`TestDarwinDownload_PublishAndAbort`、`TestDarwinDownload_CompetitionAndReplacement`、`TestDarwinDownload_RejectsUnsafePart`、`TestDarwinRuntimeLogs_WriterOutlivesDirectory`、`TestDarwinRuntimeLogs_ConditionalRemove`、`TestDarwinRuntimeLogs_CapacityAndLinks`：精确对象发布、竞争目标保留、替换 part 不误删、父能力关闭后 writer 可用、过期 token 失败关闭。
- 绿灯：FD 相对创建/写入/同步；`renameatx_np(RENAME_EXCL)` 发布；普通文件及单链接校验；有身份绑定的条件移除。记录发布已经生效与关闭失败的区别。
- 协作并发：下载目录 FD 上的短时 flock 串行化 Begin 的 stale/create/锁定；part FD 的独占 flock 持有到会话收口，其他 Runtime 不能清理活跃 part。日志 writer 对文件持有共享 flock，删除要求独占 flock；目录 FD 的短时独占锁串行化追加容量检查与写入，允许多个 writer，关闭父能力不释放 writer 自己的 FD。全部等待支持 ctx 或有界预算，不新增私有路径，也不宣称 flock 强制隔离同 UID 非协作方。
- 验证：双 APFS 原生定向 + race、Windows 标准门；独立提交与审查。

## Task 3：分类删除和重命名

- 文件：`delete_darwin.go`、`rename_darwin.go` 及对应测试。
- 红灯：`TestDarwinOperator_DeleteKinds`、`TestDarwinOperator_ProtectedAndMismatched`、`TestDarwinOperator_UnsafeTreeIsPreserved`、`TestDarwinOperator_IdentityAndAudit`、`TestDarwinOperator_PartialRemovalIsReported`、`TestDarwinOperator_RenameKinds`、`TestDarwinOperator_RenameNoReplaceAndIdentity`：分类/精确路径不符、保护目录、未知身份、链接子树、目标竞争、审计失败、部分副作用及取消。
- 绿灯：所有授权来自 config；先完整无链接扫描，再 FD 相对递归移除；不猜测未知现场。重命名 no-replace，源/目标身份与用途匹配，保留双阶段审计与副作用结果。
- 分类规则与审计字段校验从 Windows 实现提取成共用纯逻辑，Windows 机制不变；Darwin 在创建/删除前逐层检查设备与对象身份。预检深度上限 256、总条目上限 1,000,000，超出时保留目标并失败关闭，不用部分扫描授权删除。
- 验证：分类表逐项映射、外部哨兵、双 APFS/race、Windows 标准门；独立提交与审查。

## Task 4：rooted Git 文件系统

- 文件：`internal/filesystem/rooted_darwin.go`、`internal/gitrepo` 的 Darwin billy adapter、clone / verify / alpha / check / stage / recovery / restore 接线；测试保留 Windows 专属的禁止重命名语义，Darwin 以 FD 对象与根外哨兵替代。
- 红灯：`TestDarwinRepository_RejectsExternalGitDirectory` 证明旧 `PlainOpen` 能读取仓库外的 `.git`。`TestDarwinGitFS_RejectsEscapeAndLinks`、`TestDarwinGitFS_RetainsOriginalRoot`、`TestDarwinGitFS_ClosesAndCancels` 分别证明原始路径和 Chroot 不逃逸、根替换不会改变授权对象、打开文件在操作结束时被关闭。
- 绿灯：生产调用从已经持有的目录租约派生 FD 根，同一操作的工作树和 `.git` 共享它。每个路径组件拒绝越界和链接，拒绝其他卷、特殊文件、多硬链接；`Chroot` 只追加安全的相对组件。根路径检测到替换时中止；任何未发现的窗口也不会改用新根。拒绝 `.git` 文件、外部 alternates 和 common dir。Go-git 文件在操作作用域关闭；恢复的 Git 读取同样接入，源码 FD 读写继续在 Task 5 验收。
