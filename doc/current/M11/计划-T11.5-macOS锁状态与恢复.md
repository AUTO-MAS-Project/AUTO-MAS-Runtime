## Task 1：稳定的 flock 锁集

- 文件：`internal/config/darwin_locks.go`、`internal/filesystem/rooted_locks_darwin.go`、`internal/lock/set_darwin.go`、Darwin 锁测试、非 Darwin 桩 build tag、macOS 原生工作流。
- 红灯：以现有 unsupported 桩运行 `TestDarwinLock_StagingMatrix`，应在 `NewSet` 失败。其他原生测试为 `TestDarwinLock_HolderCrash`、`TestDarwinLock_RejectsReplacedObjects`、`TestDarwinLock_ConcurrentCrossAcquire`、`TestDarwinLock_ReadOnlyProbeAndCancel`。

- 验证：Windows 标准门与 race、Darwin ARM64 完整构建及锁测试编译；原生两档 Runner、双 APFS 的 `go test -race -v ./internal/lock -run '^TestDarwinLock_' -count=100 -timeout=5m`。单独提交、审查，推送按 AGENTS.md §6.7 授权。
