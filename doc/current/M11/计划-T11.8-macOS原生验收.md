生产修改先运行对应红灯并确认失败原因，修复后重复同一命令和相关包验证。按表逐项审查与提交。锁补证若发现实现缺陷，提交改用 `fix`。

阶段性原生入口为 `.github/workflows/macos-prototype.yml`，包含 macOS 15/26 ARM64、默认及大小写敏感 APFS 的定向能力矩阵。工作流调用前须获得远端写入授权。也可在对应原生主机用同一工作树运行以下命令。

```sh
go test -race -v ./internal/lock -run '^TestDarwinLock_' -count=100 -timeout=5m
go vet ./...
go build -buildvcs=false ./...
go test ./... -count=1
go test -race ./... -count=1
```

定向测试检查退出码、实际命中的 PASS 行和无测试命中提示。三批能力门使用本表各自的 CLI 黑盒用例，须取得两档原生结果才可正式提交。最终 CI 使用该批固定用例和真实 Runtime 二进制保留 transcript。交叉编译单独记录。
