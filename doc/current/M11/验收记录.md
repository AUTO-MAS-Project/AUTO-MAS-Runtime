## 独立审查与修复

两位独立审查者分别检查文件系统/锁/进程与部署/发行。发现并修复：
递归删除缺少持续祖先验证、可替换锁文件导致双租约、guardian FD 泄漏与异常退出兜底、
同 Set 租约覆盖、诊断路径权限错误阻断回收、Python 安装布局误判、输出过早截断、
清理取消未贯通回调、doctor 探针写缓存。审查者已对其报告的重要问题定向复审关闭。
对应复现已纳入回归测试；不把定向复审等同于所有平台验收。

维护者后续审查补充：uv 0.12.3 在正常持久化 wheel 时会创建缓存内部链接，
Linux `cleanup` 必须能安全删除该链接条目。实现仅对 `DeleteUVCache` 的叶子链接
启用 no-follow 身份核验后 unlink；祖先链、其他删除类别和目标遍历边界不变。

## POSIX 安全保证范围

目录 FD 与每步祖先身份验证避免跟随未知链接，并在观察到迁移/替换时停止。
POSIX 没有 Windows deny-delete/rename 的等价能力，检查与后续系统调用之间不是原子的；
不宣称可抵御恶意同 UID 在该窗口内的任意 rename 竞态。
根 inode 租约要求本机 flock/xattr 支持，不支持网络文件系统，不支持直接篡改租约扩展属性。
已有恢复状态机继续消费正式状态文件；未发布的随机临时文件不被猜测为新的状态权威。
