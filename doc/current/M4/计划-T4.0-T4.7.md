# M4 工作区同步实施计划

状态：执行中（2026-08-05；T4.0~T4.2 已完成）。设计基线：[M4 工作区同步设计](./设计-M4-工作区同步.md)。

执行纪律：每个 Task 严格按“红灯 -> 绿灯 -> 定向验证 -> 审查 -> 独立提交”推进；测试函数名
在实施中不得无故改名。每次只暂存该 Task 明列文件，提交前执行 `git diff --check`。计划完成后
删除，由 Git 历史追溯。

2. 对 GitHub/CNB 的 `release/v5.3.1` 分别执行

5. 运行 `go mod verify`、标准门，提交 `chore: 固定并验证 go-git 浅克隆 (T4.0)`。
