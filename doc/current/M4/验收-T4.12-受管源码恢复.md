## 实现

- Runtime 按 Git tree 和 blob 哈希恢复全部已检出跟踪文件，跳过 frontend/.debug；忽略 index，保留未跟踪文件。Commit/tree 的原始对象也校验哈希。每个普通文件在固定父目录下以 flush 后的临时文件原子替换，源文件读取不共享写入且拒绝 Reparse。
- 两处同 revision 复用路径共用恢复出口。写入前持久化 repository_changed/workspace.verify/exit 0，恢复成功仍保持 broken 并返回 changed=true，交给 bootstrap 完整同步依赖。占用/取消后保留 broken，下次重跑；损坏 Git 对象或无法证明安全的路径失败关闭。
- TOML 语法预检新增 LOCKFILE_INVALID，uv 非零退出无法证明过期时新增 LOCKFILE_CHECK_FAILED；恢复失败新增 WORKSPACE_RESTORE_FAILED。旧 LOCKFILE_OUTDATED 四元组保留。新码复用原诊断白名单和遥测分类，不上传源文件内容或原始错误文本。
- MAS 普通启动的 bootstrap 自动得到恢复能力；局部锁检查失败最多自动转完整 bootstrap 一次。失败界面提供独立的“恢复程序文件并重试”，成功后进入后端启动阶段；仅 managed 模式恢复，development 不修改开发者源码。
