# T4.12 受管源码恢复

2026-10-18，用户授权直接在 main 实现。

## 设计

repo 的已检出跟踪文件以本地已验证 Commit 为准。按 tree 遍历，跳过稀疏排除项，以 Git blob 哈希核对普通文件；修改与缺失进入恢复队列，加载并验证原始 blob 后才开始写入。不依赖可被修改的 index，不改 HEAD、不联网、不触碰未跟踪文件。符号链接、目录冲突与损坏对象失败关闭。文件路径由 config 提供。

持 mutation 锁并确认后端未运行后，首次恢复前持久化 environment_broken/repository_changed。固定父目录，拒绝 Reparse，以临时普通文件写入、flush、原子替换；失败和取消保留 broken，下次 bootstrap 重跑。恢复成功返回 Changed=true，迫使 bootstrap 同步依赖。两处同 revision 快路径共用恢复出口，普通干净启动无写入。日志记录恢复事实和数量，不输出文件内容。

MAS 普通启动本就运行 bootstrap，自动获得恢复；失败页提供一键恢复，执行完整 bootstrap 并延续初始化。局部依赖重试发现锁文件异常时自动转 bootstrap 一次，禁止递归重试。显式恢复不受旧 LOCKFILE_OUTDATED 的普通重试限制，不把无效锁重新解析成新依赖。
