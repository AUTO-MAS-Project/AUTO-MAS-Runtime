# T4.11 仓库删除占用重试设计

## 目标

受管目录删除因 Windows 文件占用、锁定或临时拒绝访问失败时，每隔 10 秒重试一次，最多重试 3 次，减少杀毒软件或残留句柄造成的初始化失败。

## 边界

- 重试只覆盖 `ERROR_SHARING_VIOLATION`、`ERROR_LOCK_VIOLATION` 和 `ERROR_ACCESS_DENIED`。
- 每次重试沿用已固定的受管目录句柄，不放宽允许删除的目录范围。
- Reparse、身份变化、路径越界、审计错误和其他错误立即返回。
- Git 的独立清理 context 使用 60 秒预算，容纳三次 10 秒等待。

## 验收

以一个确定性测试证明前三次删除返回占用错误、三次等待均为 10 秒、第四次删除成功；随后执行标准验证门。
