# T1.9 M1 对抗审查修复实施计划

## 1. 执行规则

- 严格按红灯、最小实现、回归验证的顺序处理行为变化；
- 仅修改 T1.9 涉及文件，不回退当前工作树中的 T1.7/T1.8 或用户改动；
- 所有 PowerShell 原生命令后检查 `$LASTEXITCODE`；
- 定向 `-run` 测试还需确认输出不含 `[no tests to run]` 且包含 `--- PASS:`；
- 不提交、不推送，除非用户另行明确要求。

## 2. Task 1：Emitter 所有权与 renderer 夹具

文件：`internal/protocol/emitter.go`、`emitter_test.go`、`human_renderer_test.go`、
`values_test.go`。

先补未知 capability、构造期修改原切片、renderer 直测和 capability 防御性副本测试，确认红灯；
再复制入口切片并调整夹具。移除过宽的全文 `:null` 搜索，保留字段级 wire 类型断言。

## 3. Task 2：完整 contracttest schema

文件：`internal/protocol/errors.go`、`errors_test.go`、`contracttest/validate.go`、
新增 `contracttest/schema.go` 与对应测试，并调整公共夹具和 demo。

先覆盖七种事件缺字段/错类型、六类未知冻结值、null 容器、错误定义错配和 `OK` 误用；
再实现集中 schema 校验并把正例改为权威构造器生成的数据。

## 4. Task 3：生命周期文档驱动与并发证据

文件：`internal/protocol/lifecycle_test.go`、`doc_fixture_test.go`、`errors_test.go`、
必要的同包白盒并发测试文件。

先新增文档解析测试，确认旧硬编码仍是唯一来源；再删除硬编码全集并让相关测试共享解析结果。
Emitter 在调用 result renderer 前于同一锁域预约终态，renderer 失败时回滚；同包测试同时观察
终态预约和锁持有状态，并用阻塞 renderer 钉住临界窗口；既有 concurrent results 测试继续覆盖
竞争调用。生命周期恢复同一实例的并发读写与并发 restart guard，作为 race detector 的实际访问
覆盖；不增加生产 test hook，无法由公开行为确定性证明的调度风险在复审中明确记录。

## 5. Task 4：验证脚本与计划修正

修正 `doc/计划-T1.7-M1契约收口实现.md` 及复审发现的历史计划中全部原生命令退出码检查、
定向测试命中检查与已过期工具链说明；同步更新 `AGENTS.md`、`CLAUDE.md` 和 `README.md`。
运行标准验证门和 100 次高重复测试；随后执行双视角独立对抗审查，修复新增的
Critical/Important，最后回写 T1.9 状态与审查报告。

## 6. 最终验证命令

```powershell
$go = (Get-Command go -ErrorAction Stop).Source
$gofmt = (Get-Command gofmt -ErrorAction Stop).Source
$gccBin = Split-Path -Parent (Get-Command gcc -ErrorAction Stop).Source
$env:PATH = "$gccBin;$env:PATH"
$env:GOCACHE = Join-Path $env:TEMP "auto-mas-runtime-t19-verify"

$unformatted = & $gofmt -l .
if ($LASTEXITCODE -ne 0) { throw "gofmt failed" }
if ($unformatted) { $unformatted; throw "gofmt found unformatted files" }
& $go vet ./...
if ($LASTEXITCODE -ne 0) { throw "go vet failed" }
& $go build -buildvcs=false ./...
if ($LASTEXITCODE -ne 0) { throw "build failed" }
& $go test ./... -count=1
if ($LASTEXITCODE -ne 0) { throw "tests failed" }
& $go test ./internal/protocol ./internal/protocol/contracttest -count=100
if ($LASTEXITCODE -ne 0) { throw "repeated tests failed" }
& $go test -race ./... -count=1
if ($LASTEXITCODE -ne 0) { throw "race tests failed" }
git diff --check
if ($LASTEXITCODE -ne 0) { throw "diff check failed" }
```
